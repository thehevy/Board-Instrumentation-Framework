```
6. Legend: Show/hide legend
```

## 🎓 Design Patterns

### Gauge Color Zones - Real-World Inspired
The 3-zone preset (70%/90% thresholds) comes from industry standards:
- **IT Monitoring**: CPU/Memory warnings at 70%, critical at 90%
- **Industrial Control**: Process parameters follow similar ranges
- **SLA Compliance**: 70% = yellow light, 90% = escalation trigger

Users can override with custom zones, but 90% use the preset.

### Chart Time-Series - Performance Optimized
- Default 60-second window balances:
  * **Visibility**: Enough history to see trends
  * **Performance**: Limited data points for smooth rendering
  * **Responsiveness**: Quick updates without lag
- Configurable from 10 seconds to 10 minutes

### Multi-Series Color Selection
Colors chosen for maximum contrast:
- Blue, Green, Red, Orange, Purple, Cyan
- Colorblind-friendly primary options
- High contrast on both light and dark backgrounds
- Matches Marvin's default color scheme

## 🔧 Technical Notes

### Gauge Color Zones Implementation
```python
# 3-zone preset calculation
range_span = max_val - min_val
zone1_end = min_val + (range_span * 0.7)  # 70%
zone2_end = min_val + (range_span * 0.9)  # 90%

zones = [
    {'start': min_val, 'end': zone1_end, 'color': 'rgb(0, 255, 0)'},
    {'start': zone1_end, 'end': zone2_end, 'color': 'rgb(255, 255, 0)'},
    {'start': zone2_end, 'end': max_val, 'color': 'rgb(255, 0, 0)'}
]
```

### Chart Series Collection
```python
# Supports unlimited series
while True:
    source = select_data_source()
    if not source and len(series_list) >= 1:
        break  # Done, have at least one
    
    label = prompt_label()
    color = prompt_color()
    
    series_list.append({'source': source, 'label': label, 'color': color})
    
    if not prompt("Add another? (y/n)"):
        break
```
